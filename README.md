# Supply and Order Management System

## Project Overview
This project presents a relational database system designed to manage suppliers, products, customers, and orders efficiently.

## Objectives
- Design a normalized database.
- Create relationships between business entities.
- Implement CRUD operations using SQL.
- Develop a user-friendly application interface.

## Database Components
- Suppliers
- Products
- Customers
- Orders

## Technologies Used
- Oracle Database
- SQL
- Oracle Application Express (Oracle APEX)

## Features
- Product management
- Supplier management
- Customer management
- Order processing
- Data retrieval through SQL queries

## Project Workflow
1. Database design
2. ERD creation
3. Normalization
4. SQL implementation
5. Application development in Oracle APEX

## Results
Developed a fully functional database management system with normalized tables and an interactive application interface.
